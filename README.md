# SkolSchedule

Неофициальное месячное представление публичного расписания Skoltech.

## Возможности

- месяц разбит на пятидневные строки-недели (понедельник–пятница) с общей вертикальной шкалой времени;
- занятия одинакового времени выровнены по горизонтали, а пересечения размещаются рядом;
- клик по курсу открывает его официальный syllabus (если ссылка опубликована);
- пересекающиеся по времени занятия после применения фильтров выделяются красным;
- множественный выбор курсов, фильтры по преподавателю, программе, аудитории и текстовый поиск;
- выбор всех доступных учебных периодов из публичного Skoltech API;
- адаптивная вёрстка, на узких экранах календарь прокручивается горизонтально.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm start
```

Откройте <http://localhost:3000>.

Для разработки с автоматическим перезапуском:

```bash
npm run dev
```

Тесты:

```bash
npm test
```

## Источник данных

Приложение использует публичный API `https://schedule.skoltech.ru:8443/api/v1`. Node-сервер выступает proxy, объединяет дневные ответы в месяц и кэширует их на 15 минут. Данные и доступность syllabus зависят от источника. Никакие учётные данные не требуются и не сохраняются.

На GitHub Pages приложение автоматически переключается в статический режим и обращается к публичному Skoltech API напрямую. API разрешает браузерные CORS-запросы, поэтому отдельный сервер для Pages не нужен.

Последующие изменения публикуются командами:

```bash
git add .
git commit -m "Update schedule"
git push
```
